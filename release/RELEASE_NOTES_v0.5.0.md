## 更新摘要
交互功能与布局重大升级：1. 新增网页双屏分屏并行浏览 (SplitBrowserPanel)，支持左右同屏浏览、中缝拖拽调节、左右页面对调 (Alt+D)；2. 新增纯净沉浸式阅读模式 (Reader Mode)，智能提取正文与标题，支持白天/羊皮纸/深色三套主题及字号缩放 (Alt+R / Esc)；3. 新增视频独立置顶画中画浮窗支持 (Picture-in-Picture)；4. 新标签页速拨面板新增搜索引擎即时切换下拉器与开发者每日灵感寄语；5. 地址栏右侧新增智能缩放指示芯片，支持一键恢复100%。
