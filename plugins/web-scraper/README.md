# 可视化网页爬虫（LfsunBrowser 插件版）

这是 [`lfsun-win-browser`](https://gitee.com/pc-app/lfsun-win-browser) 自带的**可视化**网页爬虫插件。
**不用写代码**，只用鼠标点一点就能从任意网页抓取结构化数据，导出 CSV / JSON。

## 三步即可上手

1. **打开爬虫面板**：按 `Ctrl+Alt+G` 或点击右下角 🔍 浮动按钮
2. **点"启用选点"按钮**，鼠标移到页面的**列表区域**上（橙色虚线框），点击选取整个容器
   - 插件自动识别页面上所有**相似的条目**（比如电商商品卡片、搜索结果列表）
   - 自动预填可能的字段（标题、链接、图片等）
3. **切换"预览"Tab** 立即查看抓取结果 → 点"导出CSV"或"导出JSON"下载

## 进阶操作

- **添加更多字段**：选完容器后，点"添加字段"，再点击容器内的具体元素（如价格、作者、时间等），点击即选中，再点即取消
- **管理字段**：在"字段"Tab 里可以删除不需要的字段、看每字段的真实预览值
- **实时预览**：任何操作都会即时在"预览"Tab 刷新表格，所见即所得

## 智能特性

- **自动识别容器**：点击一块区域，自动判断页面上有多少个"长得一样"的条目
- **自动生成选择器**：不需要知道什么是 CSS 选择器，插件内部自动生成唯一且简洁的路径
- **字段类型自动判断**：链接(a)、图片(img)、文本自动识别
- **子字段联动**：选取大容器后，内部字段自动生成为子选择器

## 安装

把 `plugins/web-scraper/` 整体放到浏览器的插件目录：
- 开发运行：构建输出下的 `plugins/`（如 `bin/Release/net8.0-windows/plugins/`）
- 已安装版：程序目录下的 `plugins/`

然后在浏览器「设置 → 插件」启用，或打开新页面自动加载。

## 快捷键

- `Ctrl+Alt+G`：开关爬虫面板
- `Esc`：取消当前选点状态
